Dockside Changelog

v2.9.29

Join our Discord/Reddit Community | Bugs: hachipoo.apps@gmail.com

New Features

  • You can now drag out individual files from the stack preview.
  • Enable/disable stacks in the shelf.
  • Added an option to toggle auto-stacking in the right/bottom shelf.
  • Reverse hide mode is now available in Dockside for those power users! Enable this in the Settings > Dock Behaviours.

Fixes

  • Fixed false drag detections.
  • The drop shelf shake to drop gesture is further tuned.
  • General improvements and user feedbacks.
  • Fixed an clipboard related bugs.
  • Fixes few minor aesthetics and shelf design related bugs.
  • Shelf file limit is imposed by the areas configured in the shelf (if configured), that way you won't lose what's on the other area when max limit reaches and the oldest file is removed automatically.
