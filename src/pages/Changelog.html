Dockside Changelog

v2.9.37

Join our Discord/Reddit Community | Bugs: hachipoo.apps@gmail.com

New Features

  • The all new search panel in the shelf is integrated with the best app out there from Lowtechguys called "Cling", if you already have it, Dockside automatically will integrate with it for system-wide search! You can download this app for free and it's free to use for Home and Applications.
  • The file previews in the expanded mode now appears when hovering over the card vs. the icon itself.
  • New utilities for images and text files in shelf
  • Added easy to access undo button for destructive actions in the shelf.
  • Search in files shelf is now better and useful than just shelf search, you can view your recently dropped files, categorised and searchable.
  • Better music controls (dedicated panel now) for select apps (Spotify and Apple Music) for now.

Fixes

  • Core optimisations to improve performance, the app must feel more quick and responsive now.
  • Refinements to popovers + more options + escape key works as expected for few actions
  • Helper popovers to reset search and many other useful actions on the shelf
  • Fixed a bug where the file count pill in vertical mode was not showing up
  • Updated the file count pill size to be proportional to the icon on the shelf especially when it's very tight around the Dock.
  • Fixed a bug that triggering Files area to be shown in the shelf when multiple drop areas are configured, triggered when dragging a file out of the files shelf.
  • Fixed theme setting for expanded shelf in transparent mode.
  • Instant right click context menus + improvements to the settings panel navigation and reduced sluggishness.
  • Improved extract text from image panel.
  • Optimised message banners
  • Minor updates to the bulk selection popovers
  • General improvements and bug fixes
  • Calendar widget was still asking for permission, fixed the bug.
